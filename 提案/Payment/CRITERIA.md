## 一、通用規則

### 1.1 商戶分類

| 分類 | 判斷條件 |
|------|----------|
| 銀行卡 | 商戶包含「极速充提3」且不含「支付寶/微信」 |
| 支付寶 | 商戶包含「支付寶」或「支付宝」 |
| 微信 | 商戶包含「微信」 |
| 線下 | 商戶包含「線下」或「线下」 |

### 1.2 排除條件

以下記錄在計算時排除：
- 商戶包含 `test`（不區分大小寫）
- 商戶包含 `qa`（不區分大小寫）
- 商戶包含 `線下` 或 `线下`

### 1.3 處理時間計算

```
處理時間 = 通知時間 - 建立時間（秒）
```

## 二、全部區塊

### 2.1 數據範圍

```
商戶只排除 test/qa（不排除線下、外部商戶等）
```

### 2.2 重要信息

| 項目 | 計算公式 |
|------|----------|
| **总申请笔数** | 商戶只排除 test/qa 的筆數加總 |
| **总充值成功（含掉单）** | 到帳金額 > 0 的筆數 |
| **充值成功率** | 总充值成功 / 总申请笔数 × 100% |
| **总充值金额** | 到帳金額 > 0 的到帳金額加總 |
| **平均处理时间** | 到帳金額 > 0，（通知時間 - 建立時間）的平均 |
| **无效申请** | 狀態含「取消」或到帳金額 = 0 |
| **无效申请占比** | 无效申请 / 总申请笔数 × 100% |
| **掉单笔数** | 到帳金額 > 0 且狀態含「補」 |
| **掉单占比** | 掉单笔数 / 总充值成功 × 100% |

### 2.3 24小时交易分布

### 3.7 三方代收區塊

#### 數據範圍
```

```
銀行卡代號符合「報表三方設定」中配置的任一卡代號（不區分大小寫，前綴匹配）

| 項目 | 計算公式 |
|------|----------|
| **寶轉卡渠道 申請** | 商戶包含「轉卡」且 銀行卡代號 = `AUCTION_PAYMENT_CARD` 且 銀行名稱 = 支付寶 |

#### 整體配對成功率
```
分子 = 銀行卡訂單成功極速提金額 + 支付寶訂單成功極速提(卡)金額 + 支付寶訂單成功極速提(寶)金額
分母 = 支付寶提現申請金額 + 銀行卡提現申請金額（來自提現分析）
配對成功率 = 分子 / 分母 * 100%
```

### 6.10 提現計算流程

```
1. 商戶分類過濾
   - 過濾出銀行卡/支付寶/微信/線下商戶的記錄
   - 排除不屬於任何分類的記錄

2. 按訂單號去重
   - 同一訂單號保留最後一筆記錄
   - 確保統計不重複

3. 提現成功/失敗判斷
   - 成功：(說明=轉帳完成 OR 提現狀態含提現完成) 且 實際轉出金額≠0
   - 失敗：說明≠轉帳完成 且 實際轉出金額=空白或0 且 提現狀態≠提現完成

4. 時間區段分類
   - 依處理時間（秒）分類到對應區段
   - 僅統計提現成功的記錄

5. 渠道統計
   - 依商戶名稱判斷渠道（銀行卡/支付寶/微信）
   - 各渠道獨立計算提現申請和平均時間

6. 從充值數據取得配對率相關數據
   - 充值申請、成功配對、訂單成功等來自 depositMetrics
```

| **订单成功(Js+一般提)** | 銀行卡極速提 + 支付寶極速提(卡) + 極速提(寶) | expressOrderSuccessCount + alipayJisuTikaOrderSuccessCount + alipayJisuTibaoOrderSuccessCount |
| **订单成功(加总笔数)** | 一般卡 + Js+一般提 | orderSuccessTotal |
| **配对后成功率** | 訂單成功加總 / 充值配對總數 × 100% | successAfterMatchRate |

#### 9.1.4 訂單成功（金額）

| 項目 | 計算公式 | 說明 |
|------|----------|------|
| **配一般卡充值订单成功(金额)** | 銀行卡訂單成功一般卡金額 + 支付寶訂單成功一般卡金額 + 一般寶金額 | normalOrderSuccessAmount + alipayNormalOrderSuccessAmount + alipayBaoOrderSuccessAmount |
| **配极速充值订单成功(金额)** | 銀行卡訂單成功極速提金額 + 支付寶極速提(卡)金額 + 極速提(寶)金額 | expressOrderSuccessAmount + alipayJisuTikaOrderSuccessAmount + alipayJisuTibaoOrderSuccessAmount |
| **充值订单成功(金额)总计** | 配一般卡金額 + 配极速金額 | orderSuccessAmountTotal |

#### 9.1.5 騙分相關

| 項目 | 計算公式 | 說明 |
|------|----------|------|
| **骗分金額** | 銀行卡人工金額 + 銀行卡信評金額 + 支付寶人工金額 + 支付寶信評金額 | fraudAmount |
| **骗分成本占比** | 騙分金額 / 配极速充值订单成功(金额) × 100% | fraudCostRatio |
| **JS提现返利** | 提現記錄中的 merchantRebate 加總金額 | jsWithdrawRebate |

#### 9.1.6 提現相關

| 項目 | 計算公式 | 說明 |
|------|----------|------|
| **提现平均时间（卡）** | 銀行卡渠道平均處理時間 | withdrawAvgTimeBankCard |
| **提现平均时间（宝）** | 支付寶渠道平均處理時間 | withdrawAvgTimeAlipay |
| **提现失败率** | 提現失敗筆數 / 總申請筆數 × 100% | withdrawFailRate |

### 9.2 指標數據分析

#### 9.2.1 充值指標計算公式

| 指標 | 計算公式 |
|------|----------|
| **充值成功率** | 到帳金額 > 0 的筆數 / 總申請筆數 × 100% |
| **3分內占比** | 處理時間 ≤ 180秒的筆數 / 充值成功筆數 × 100% |
| **平均處理時間** | 到帳金額 > 0 的處理時間平均 |

#### 9.2.2 充值分類數據範圍

| 分類 | 數據範圍 |
|------|----------|
| **整體** | 商戶只排除 test/qa |
| **支付寶** | 商戶含「支付寶/支付宝」且不含 test/qa/線下 |
| **微信** | 商戶含「微信」且不含 test/qa/線下 |
| **金寶** | 銀行卡代號 GB 開頭（排除 GB-Dahaomen），排除線下商戶 |
| **極速** | 銀行卡代號 AUCTION 開頭，排除線下商戶 |
| **第三方** | 銀行卡代號非 AUCTION/GB 開頭，或 GB-Dahaomen 開頭，排除線下商戶 |
| **非正向信評** | 狀態以「信用」或「信评」或「信評」開頭 |

#### 9.2.3 提現指標計算公式

| 指標 | 計算公式 |
|------|----------|
| **提現成功條件** | (說明=轉帳完成/转账完成/转帐完成 OR 提現狀態含提現完成/提现完成) 且 實際轉出金額≠0 |
| **提現成功率** | 提現成功筆數 / 總申請筆數 × 100% |
| **2分內占比** | 處理時間 < 120秒的筆數 / 提現成功筆數 × 100% |
| **平均處理時間** | 提現成功的處理時間平均 |

#### 9.2.4 提現分類數據範圍

> **注意**：所有提現分類均按訂單號去重

| 分類 | 數據範圍 |
|------|----------|
| **整體** | (銀行卡 + 支付寶 + 微信) + 線下，按訂單號去重 |
| **支付寶** | merchant 含「支付寶/支付宝」，按訂單號去重 |
| **微信** | merchant 含「微信」，按訂單號去重 |
| **金寶** | payoutCardCode 以 GB 開頭（非 GB-Dahaomen），按訂單號去重 |
| **極速** | payoutCardCode 包含 AUCTION，按訂單號去重 |
| **第三方** | payoutCardCode 不為空且不包含 AUCTION，按訂單號去重 |
