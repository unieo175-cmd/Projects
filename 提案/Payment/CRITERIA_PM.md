## 一、數據範圍定義

### 1.1 數據來源

```
此頁面使用獨立數據，不與其他頁面共用。
數據儲存於 IndexedDB (PmMetricsDB)。
```

### 1.2 分類篩選條件

| 分類 | 篩選條件 |
|------|----------|
| **整體** | 商戶排除包含「線下」、「test」、「qa」的商戶名稱 |
| **支付寶** | 商戶包含「支付宝」或「支付寶」 |
| **微信** | 商戶包含「微信」 |
| **金寶** | 商戶排除線下/test/qa，銀行卡代號 GB 開頭（排除 GB-DAHAOMEN）|
| **極速** | 商戶排除線下/test/qa，銀行卡代號 AUCTION 開頭 |
| **三方** | 商戶排除線下/test/qa，銀行卡代號非 GB/AUCTION 開頭，或 GB-DAHAOMEN |
| **非正向信評** | 商戶排除線下/test/qa，狀態以「信用」或「信評」開頭 |

## 二、筆數計算

### 2.1 充值筆數計算

| 指標 | 計算公式 |
|------|----------|
| **自動到帳** | 到帳金額 > 0 且狀態不包含「補單」|
| **補單** | 到帳金額 > 0 且狀態包含「補單」或「商戶確認到帳」|
| **總充值筆數** | 自動到帳 + 補單 |
| **無效申請** | 到帳金額 = 0 且狀態包含「未充值」|
| **自動到帳時長** | 自動到帳筆數的平均處理時間（通知時間 - 建立時間）|
| **平均充值時長** | （自動到帳 + 補單）的平均處理時間 |

### 2.2 提現筆數計算

| 指標 | 計算公式 |
|------|----------|
| **總提現筆數** | 符合分類條件的提現記錄數 |
| **提現成功** | 轉帳成功 且 實際轉出金額 ≠ 0 |
| **平均提現時長** | 提現成功筆數的平均時間 |

#### 提現時間計算公式
```
IF(V="", Q-T, Q-V)

Q = 通知商戶時間
T = 建立時間
V = 剩餘池建立時間
```

### 2.3 筆數計算表格欄位

| 欄位 | 說明 |
|------|------|
| **分類** | 整體/支付寶/微信/金寶/極速/三方/非正向信評 |
| **總充值筆數(自動到帳+補單)** | 充值成功總筆數 |
| **補單筆數** | 補單的筆數 |
| **無效申請筆數** | 無效申請的筆數 |
| **自動到帳筆數** | 自動到帳的筆數 |
| **自動到帳時長** | 自動到帳的平均處理時間 |
| **平均充值時長** | 總充值的平均處理時間 |
| **總提現筆數** | 提現申請總筆數 |
| **提現成功筆數** | 提現成功的筆數 |
| **平均提現時長** | 提現成功的平均處理時間 |

## 三、指標數據分析

### 3.1 充值指標

| 指標 | 計算公式 |
|------|----------|
| **成功率** | 自動到帳筆數 ÷ 總充值筆數 × 100% |
| **3分內佔比** | 自動到帳中處理時間 ≤ 180秒的筆數 ÷ 自動到帳筆數 × 100% |
| **平均處理時間** | 自動到帳筆數的平均處理時間（通知時間 - 建立時間）|

### 3.2 提現指標

| 指標 | 計算公式 |
|------|----------|
| **成功率** | 提現成功筆數 ÷ 總提現筆數 × 100% |
| **2分內佔比** | 提現成功中處理時間 ≤ 120秒的筆數 ÷ 提現成功筆數 × 100% |
| **平均處理時間** | 提現成功筆數的平均時間，公式 IF(V="", Q-T, Q-V) |

### 3.3 指標數據表格欄位

| 欄位 | 說明 |
|------|------|
| **分類** | 整體/支付寶/微信/金寶/極速/三方/非正向信評 |
| **充值-成功率** | 充值成功率 |
| **充值-3分內佔比** | 3分鐘內完成的比例 |
| **充值-平均處理時間** | 充值平均處理時間 |
| **提現-成功率** | 提現成功率 |
| **提現-2分內佔比** | 2分鐘內完成的比例 |
| **提現-平均處理時間** | 提現平均處理時間 |

## 四、充值分析

### 4.1 數據範圍

### 4.2 分析欄位

| 欄位 | 說明 |
|------|------|
| **分類** | 商戶分類或補單類型 |

| **金額佔比** | 金額佔總金額的百分比 |
| **平均時間** | 該分類的平均處理時間 |

## 五、欄位對照表

### 5.1 充值數據 CSV 欄位

| CSV 欄位名稱 | 系統變數 | 說明 |
|-------------|----------|------|
| 到帳金額 / 到账金额 | `receivedAmount` | 實際到帳金額 |
| 銀行卡編碼 / 银行卡编码 | `bankCardCode` | 銀行卡代號 |
| 收款商戶 / 收款商户 | `merchant` | 商戶名稱 |
| 狀態 / 状态 | `status` | 訂單狀態 |
| 建立時間 / 建立时间 | `createTime` | 訂單建立時間 |
| 通知時間 / 通知时间 | `notifyTime` | 通知完成時間 |

### 5.2 提現數據 CSV 欄位

| CSV 欄位名稱 | 系統變數 | 說明 |
|-------------|----------|------|
| 說明 | `transferStatus` | 轉帳狀態（轉帳完成/转账完成）|
| 實際轉出金額 / 实际转出金额 | `actualAmount` | 實際轉出的金額 |
| 出款商戶 / 出款商户 | `merchant` | 商戶名稱 |
| 建立時間 / 建立时间 | `createTime` | 訂單建立時間 |
| 通知商戶時間 | `notifyTime` | 通知商戶時間 (Q) |
| 剩餘池建立時間 | `poolCreateTime` | 剩餘池建立時間 (V) |

```
收款銀行、收款银行、收款卡號、收款卡号、收款姓名、出款商戶、出款商户、出款卡編碼、出款卡编码
```
